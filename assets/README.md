# Assets

This folder is for final presentation assets (diagrams, logos, screenshots).

## Expected structure

- `assets/diagrams/` — diagrams referenced by slides
- `assets/logos/` — company logos (SVG/JPG/PNG)

## Logo naming

Use a simple slug (lowercase, spaces→hyphens) so the presentation can auto-resolve logos, e.g.:

- `assets/logos/openai.svg`
- `assets/logos/google-cloud.svg`
- `assets/logos/uipath.svg`
