## Instructions for Logo Fetching

### Recommended Approach

1. **Use a logo API service** (recommended):
   - **Clearbit Logo API**: `https://logo.clearbit.com/{domain}` (free tier available)
   - **Logo.dev API**: `https://logo.dev/api/v1/{domain}` (paid)
   - **Simple Icons**: For open-source projects, check https://simpleicons.org/

2. **Extract domain from Primary Link**:
   - Remove `www.`, `docs.`, `github.com/`, etc.
   - Use the main domain (e.g., `anthropic.com`, `openai.com`)

3. **Save logos as SVG files**:
   - Filename format: `{slug}.svg`
   - Location: `final-presentation/assets/logos/`
   - Size: 128x128 pixels (or maintain aspect ratio)
   - Format: SVG preferred, PNG acceptable

4. **Verification**:
   - Check that logo URLs are correct by visiting the Primary Link
   - Verify the logo matches the company
   - Ensure SVG files are valid and display correctly

### Alternative: Manual Logo Collection

If using a different method:
1. Visit each Primary Link
2. Find the company logo (usually in header/footer)
3. Download as SVG or convert PNG/JPG to SVG
4. Save as `{slug}.svg` in `final-presentation/assets/logos/`

### File Format

Logos should be saved as:
- **SVG** (preferred): Vector format, scales well
- **PNG** (fallback): 128x128px minimum, transparent background preferred

The presentation will automatically look for files in this order:
1. `{slug}.svg`
2. `{slug}.png`
3. `{slug}.jpg`
4. `{slug}.jpeg`
5. `_placeholder.svg` (fallback)
