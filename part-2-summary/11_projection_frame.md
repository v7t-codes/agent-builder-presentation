# Summary: observations + projection frame

Most “agent builder” debates get confused because they compare products operating in totally different autonomy regimes.  
This slide summarizes the market and gives a clean frame to project companies into.

## What we learned (across segments)

- Value accrues where platforms reduce **operator load** (deployment + evals + governance), not where they add more “prompt routing.”
- Environment ownership (browser/desktop sessions, replays, retries) turns reliability into infrastructure.
- Verticals win by turning domain KPIs into eval harnesses (measurement becomes the moat).
- In enterprises, “no-code” wins when it’s a collaboration surface with a production finish path.
- “AI employee” packaging changes buyer/budget and raises the proof + safety bar; winners converge on the same underlying primitives.

## Projection frame (4 axes)

- **Environment surface:** `API` / `Browser` / `Desktop` / `Multi` / `Voice`
- **Task complexity:** `Low` / `Med` / `High`
- **Time sensitivity:** `Batch` / `Operational` / `Real-time`
- **Risk + consequence:** `Low` / `Med` / `High`

## How to use it (quick)

- Compare companies only inside the same regime.
- Ask: which scaffolding layer is the wedge (connectors, governance, evals, environment control, delivery)?
- Track where gravity pulls: toward suites (distribution) vs toward infra (reliability) vs toward vertical KPI ownership.
